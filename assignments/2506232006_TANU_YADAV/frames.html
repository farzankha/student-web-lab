Traditional Frames and Framesets

In older HTML, the <frameset> element was used to divide the browser window into multiple sections called frames. Each frame could load a different HTML document.

Example of Traditional Frameset

<frameset cols="25%,75%">
    <frame src="menu.html">
    <frame src="content.html">
</frameset>

The first frame could contain navigation links, while the second frame displayed the selected content.

Limitations of Frames

Limitation Explanation
SEO Problems Search engines could have difficulty indexing framed content correctly.
Accessibility Frames could make navigation difficult for screen readers.
Bookmarking Individual frame content was difficult to bookmark or share directly.
Browser History Back and forward navigation could behave unexpectedly.
Responsive Design Frames were not suitable for modern mobile and responsive layouts.
Obsolete Technology <frameset> and <frame> are not part of HTML5.

Modern Page Structure

Modern websites use semantic HTML elements such as <header>, <nav>, <main>, <section>, <article>, <aside> and <footer>. CSS Flexbox or Grid is used to create the page layout.

Modern Structure

<header>Website Header</header>
<nav>Navigation Menu</nav>

<main>
    <article>Main Content</article>
    <aside>Sidebar</aside>
</main>

<footer>Footer</footer>

This approach provides better accessibility, responsiveness, maintainability and compatibility with modern browsers.

Modern Benefits

  • Semantic structure
  • Responsive layouts
  • Better accessibility
  • Improved SEO
  • Easy maintenance
  • Flexible CSS layouts
