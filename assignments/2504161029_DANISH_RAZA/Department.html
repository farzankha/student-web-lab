Internal vs External Links

Most menu items above (Home, About, Courses, etc.) are internal links - they use a #id href that jumps to a section within the same page, so no new page is loaded and navigation stays fast. The Contact link is an external link: it points to a full URL on a different domain, opens in a new tab (target="_blank"), and uses rel="noopener" to prevent the new page from accessing this page's window object for security.
