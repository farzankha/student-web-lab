Purpose of Each Semantic Element

  • <header> - introductory content for the page: title and site branding.
  • <nav> - marks the primary navigation links, letting screen readers and browsers jump straight to menu options.
  • <main> - wraps the single, unique main content of the page (excluding repeated header/nav/footer).
  • <section> - groups a thematically related block of content, such as "Latest Updates."
  • <article> - an independent, self-contained piece of content (a single notice) that would still make sense if syndicated elsewhere.
  • <aside> - content tangentially related to the main content, like quick links or a sidebar.
  • <footer> - closing information such as copyright.

Semantic elements are preferred over generic <div> containers because they convey meaning, not just layout. Screen readers can let users jump directly to "navigation" or "main content," search engines weigh <article>/<section> content more meaningfully for indexing, and other developers can read the markup and immediately understand the page's structure without inspecting class names.
