Why Character References Are Useful

Some characters like < and & are reserved by HTML itself for tag and entity syntax, so typing them literally would either break the page's markup or be silently swallowed by the parser - entities let the browser display the symbol as plain text instead of interpreting it as code. Other entities (©, α, ×) simply provide symbols that don't exist on a standard keyboard, and using the named or numeric reference guarantees the correct character renders consistently across browsers, operating systems and fonts.
