Why Image Size and Accessibility Matter

Fixing an image's width and height keeps the page layout predictable and loading fast, since unconstrained full-resolution images would make the page look uneven and slow. Every <img> also carries a descriptive alt attribute, which is read aloud by screen readers for visually impaired visitors, displays as fallback text if an image fails to load, and helps search engines index the page correctly. The <figcaption> gives a short human-readable caption separate from the technical alt text, so sighted users get context at a glance while assistive technology still gets a full description.
